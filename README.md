# ProductApp1

ProductApp1 is an introductory ASP.NET Core application created to practice the structure of a .NET project and the basic organization of application configuration.

## Purpose

This repository was created as a first .NET project and serves as a learning foundation for building, running, and extending an ASP.NET Core application.

## How to Use

1. Install the .NET 8 SDK.
2. Review `ProductApp/appsettings.example.json` and create a local `ProductApp/appsettings.json` with your own development values. Do not commit that local file.
3. From the repository root, run `dotnet restore`.
4. Start the application with `dotnet run --project ProductApp/ProductApp.csproj`.
5. Open the local URL displayed in the terminal.

## Technology

- C#
- ASP.NET Core
- .NET 8

## Configuration

The repository includes `appsettings.example.json` as a safe configuration template. Use local development values only and keep secrets out of source control.
